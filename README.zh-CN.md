# JSONL Viewer

[English](./README.md) | **简体中文**

一个基于 Next.js 的 JSONL 文件查看器，适合浏览日志、调试数据以及逐行存储的 JSON 数据。通过多标签页、虚拟滚动和三种查看模式，让结构化数据更易阅读。

## JSONL 是什么？

JSONL（JSON Lines）是一种每行存放一条独立 JSON 数据的文本格式，例如：

```jsonl
{"level":"info","message":"服务启动","port":3000}
{"level":"warn","message":"请求耗时较长","duration_ms":1200}
{"level":"error","message":"连接失败","details":{"retry":true}}
```

每一行都可以单独解析，适合记录日志、导出数据集或保存批量处理结果。

## 功能特点

- **拖拽打开**：将文件拖入页面，或点击 **Browse Files** 选择文件。
- **粘贴日志**：无需保存文件，直接打开完整 JSON、确认后按 JSONL 逐行打开，或整段原文阅读。
- **多文件标签页**：同时打开多个文件，随时切换或关闭；每个文件独立保留搜索条件和排列顺序。
- **文件显示名称**：双击标签名称或聚焦后按 F2 原地编辑；悬停看原名，编辑时可恢复原名，不修改磁盘文件或日志内容。
- **文本搜索**：按原始 JSON 文本筛选记录，不区分大小写。
- **字段旁注**：Pretty 与 Tree 共用当前文件的精确路径说明，支持手动编辑、显示隐藏和本地 JSON 模板导入。
- **顺序切换**：按记录在文件中的顺序正序或倒序浏览，不是按字段值排序。
- **虚拟滚动**：通过 `react-window` 仅渲染列表可视区域内的记录，减少大量数据的渲染开销。
- **三种查看模式**：
  - **Pretty**：格式化显示 JSON，并对键名、字符串、数字、布尔值和 null 等进行语法高亮。
  - **Raw**：查看当前记录的原始文本，包括粘贴的多行 JSON 或普通日志。
  - **Tree**：以树结构展开或折叠对象与数组，选择字段路径并查看对应值。
- **键盘操作**：使用 ↑ / ↓ 切换记录；在 Pretty 或 Raw 模式中，使用 Ctrl+A 或 Command+A 选择详情文本。
- **内容复制**：复制当前记录或树视图中选中的值。
- **可调整布局**：拖动分隔条调整面板宽度。
- **记录大小显示**：在 **Settings** 首页通过 **Show Record Sizes** 切换每条记录的字节大小显示，沿用原本的本地偏好。
- **主题设置**：通过 **Settings → Theme** 即时切换 **Dark / Light / Warm**，不重置日志阅读状态。
- **JSON 阅读设置**：通过 **Settings → JSON Reading** 调整右侧 JSON 的字号、行高和长文本换行，不缩放左侧列表或工具栏。
- **错误提示**：无法解析的记录会标记为无效 JSON，便于定位格式问题。
- **PWA 配置**：包含应用清单和 PWA 插件配置，可在支持的浏览器及部署环境中作为独立应用安装。

## 粘贴日志

选择 **添加文件 → 粘贴日志**，空白页面也有入口。在日志内容框中主动粘贴，点击 **打开日志**：先尝试整段 JSON，完整的多行对象、数组和基本值均作为一条记录，数组不拆分。整段解析失败时先显示有效／无效数量及前 10 条候选行摘要，确认 **按行打开** 才创建来源；所有非空行都会保留，包括无效行。修改输入后旧预览立即失效。

也可以直接选择 **整段原文打开**：整个输入成为一条文本记录，即使内容是合法 JSON，也不结构化、不显示解析错误。合法记录正常使用 Pretty、Raw、Tree 和字段旁注；无效或文本记录实际使用 Raw，搜索、匹配导航、复制与正文全选都按原文处理。再次选中合法记录时恢复原有结构视图偏好。

每次成功打开都会创建独立的 **粘贴日志 N** 来源，激活并选中首条记录，独立保存搜索、排序、别名与旁注。重复内容不合并；取消或仅预览不占编号，关闭后编号不回收。名称按创建时语言生成，之后切换语言不改已有名称；支持原有改名功能，恢复和悬停显示的是初始来源名称，不伪造文件名或磁盘路径。

原文以浏览器文本框交给应用的字符串为准，不修复、不猜测、不清理前缀，也不丢弃错误行。内容仅在本地、当前页面处理，不上传、不写入浏览器存储，刷新或关闭来源后不恢复。不自动读取剪贴板、不劫持全局粘贴。超过 **5 MiB UTF-8 字节**时需要确认，提醒不代表截断上限或超大内容流畅保证。磁盘文件导入仍沿用原来的逐行解析规则。

## 快速开始

### 环境准备

请先安装与项目依赖兼容的 Node.js 和 pnpm。项目使用的 pnpm 版本可在 `package.json` 的 `packageManager` 字段中查看。

### 本地开发

在项目根目录执行：

```bash
# 安装依赖
pnpm install

# 启动开发服务器
pnpm dev
```

启动后，在浏览器中打开 [http://localhost:3000](http://localhost:3000)。

### 生产运行

```bash
# 构建生产版本
pnpm build

# 启动生产服务器
pnpm start
```

## 使用方法

1. 将 JSONL 文件拖入页面，或点击 **Browse Files** 选择一个或多个文件。
2. 点击顶部文件标签，切换需要查看的文件。
3. 在左侧搜索框输入关键词，筛选包含相关文本的记录。
4. 点击左侧列表中的记录，在右侧查看详细内容。
5. 在 **Pretty**、**Raw** 和 **Tree** 之间切换查看方式。
6. 在 **Tree** 模式中展开节点，点击字段查看路径及对应值。
7. 使用 ↑ / ↓ 切换记录，或使用顺序切换按钮倒序浏览。
8. 按需复制内容、调整面板宽度，或切换记录大小显示。

### 文件显示名称

- 双击顶部标签的名称，或通过 Tab 聚焦名称后按 F2，进入原地编辑并全选完整名称；同一时间只编辑一个标签。
- Enter 保存，Esc 取消本次修改；点击搜索框、设置或其他位置时自动保存，并继续该位置的原操作。
- 保存时去除首尾空白、保留内部空格；空名称或仅空白名称恢复原名。重复别名允许存在，不自动加编号。
- 编辑框右侧的循环箭头只在编辑时出现，点击立即恢复原文件名并退出；尚未设置别名时也可以使用。
- 悬停名称时，浮层只显示原文件名；编辑时隐藏。短名称按内容自适应宽度，长名称在标签上省略，但保存和编辑保留完整内容。
- 别名仅保存在当前页面会话，切换文件不丢失；刷新、关闭文件后重新导入或新开页面不会恢复。不重置当前记录、搜索、排序或阅读模式。

规则与验证摘要统一维护于 [整体开发文档](./DEVELOPMENT.zh-CN.md) 的 F08 节。真实系统输入法等人工验证项仍明确保留。

### 字段旁注

- 在 **Pretty** 悬停字段名，或在 **Tree** 悬停对象字段行，出现旁注按钮；也可以通过 Tab 聚焦按钮后操作。已有旁注可直接点击编辑。
- 编辑框显示当前标签标题和只读字段路径。点击 **Save** 保存，首尾空白会去除；空白说明报错，不当成删除。**Cancel**、Esc、点击遮罩均取消草稿，**Delete** 只删除说明。
- 说明按“文件 ID + 完整字段路径”关联；同一文件的匹配记录共用，不同文件各自独立。Pretty／Tree 同步，Tree 收起节点时内部说明一起隐藏。
- **Field Notes: Shown/Hidden** 是本页面统一开关；隐藏不删除数据，编辑按钮仍可用。长说明在栏内单行省略，编辑框保留完整文字与内部换行。
- 顶部 **Import Notes** 读取、校验并预览本地模板，再勾选当前打开的文件应用；默认仅选当前活动文件。文件行只显示实际标签标题，重名选项仍独立，不追加原文件名。
- 模板默认保留已有同路径旁注；明确勾选 **Overwrite existing notes at the same paths** 才覆盖模板涉及的路径，其他说明保留。任何校验错误都拒绝整份模板，不部分导入。
- 原始 JSON、Raw、Tree 的 Value 面板、搜索及匹配数量、复制和正文全选都不混入旁注；不存在对应字段时不显示、不补字段。

v1 模板格式是本版工程约定，不是外部标准：

```json
{
  "format": "jsonl-viewer-field-notes",
  "version": 1,
  "notes": [
    { "path": ["duration_ms"], "note": "总耗时（毫秒）" },
    { "path": ["processing", "duration_ms"], "note": "内部处理耗时" },
    { "path": ["reasons", 0, "type"], "note": "第一个原因的类型" }
  ]
}
```

路径从每条记录根开始，最后一段必须是对象字段名字符串。数字段是精确数组索引，`["reasons", 0, "type"]` 不会自动应用到其他元素；不支持通配符。`["a.b"]` 与 `["a", "b"]` 不同，字符串 `"0"` 与数字索引 `0` 不同。模板不写目标文件名；未知属性、重复路径、错误版本、非法路径和空说明均报错。

**旁注仅保留在当前页面会话。刷新或关闭文件后重开会丢失，包括手工修改；需要重新添加或导入外部模板。** 未勾选文件与后来新打开的文件不继承配置。本轮不提供模板导出、长期保存、磁盘写回、上传或单条日志调查备注。

交互规则、模板示例、验证摘要与待验项统一维护于 [整体开发文档](./DEVELOPMENT.zh-CN.md) 的 F06 节。

### 界面语言

- 在 **Settings → Language**（中文界面为 **设置 → 语言**）选择 **English** 或 **简体中文**，默认保持英文。
- 切换立即更新工具栏、阅读控件、设置、旁注弹窗、悬停提示、无障碍标签及校验消息，不刷新页面或重置阅读状态。
- 浏览器存储可用时保存选择，刷新后恢复，同一浏览器的其他打开页面同步更新；存储不可用时仍可在当前页面切换。
- 只翻译界面：原日志字段和值、原文件名、用户别名、旁注内容及模板 JSON 格式均保持原文。语言偏好保存不代表日志或旁注跨会话保存。

### JSON 阅读设置

- **Font Size**：默认 13px，通过加减按钮在 10～24px 间调节，每次 1px。
- **Line Height**：Compact 1.3／Standard 1.6／Relaxed 1.9，默认 Standard。
- **Wrap Long Lines**：默认开启；关闭后超长内容在相应阅读区域横向滚动，原有换行及复制内容不变。
- **Reset Reading Settings**：只恢复上述三项，不改变主题、记录大小显示或日志状态。

设置即时作用于所有文件的 Pretty、Raw、Tree JSON 内容及无效 JSON 原文。
Tree 节点保留摘要，完整值遵守阅读设置；默认节点字号统一为 13px。
排版变化时尽量保留在原阅读内容附近，不承诺滚动像素完全不变。

### 搜索高亮与两级导航

- **Filter** 沿用原文、不区分大小写的普通文本搜索，符号不作为正则；仅空白不启用搜索，有效查询的首尾空格保留。每个文件独立保存查询和排序。
- **Records** 显示筛选、排序后的位置／记录数，不是原始记录 ID；**Matches** 显示当前记录、当前模式的匹配序号／次数，不是整个文件的总次数。
- 两级导航到首尾均禁用对应按钮、不循环；Matches 不自动跨记录。重叠文字按非重叠方式计数。
- 查询变化后定位第一处匹配但不抢输入焦点；选中记录被筛掉时清除详情，不自动选择第一条。无有效查询时隐藏 Matches 和搜索提示。
- Raw 搜索原文，包括无效 JSON；Pretty 搜索完整格式化文字并保留语法颜色。模式之间允许匹配数不同；当前模式无匹配时提示切换 Raw，不自动切换。
- Tree 按深度优先、字段名在值之前统计字段名和叶子值；摘要与完整值不重复计数，生成的节点标签、索引及省略号不参与计数。导航可选择目标字段、展开必要路径并定位完整值。
- Tree 手动收起优先，不被搜索立即覆盖；再次导航到对应匹配时才展开必要路径。清空搜索撤销搜索展开，保留手动操作；全部展开／收起也属于手动操作。
- 高亮不改日志或复制内容，不重写截断预览；主题及阅读设置变化不重置活动匹配，大文件继续使用虚拟列表。

开发要求与里程碑状态见 [整体开发文档](./DEVELOPMENT.zh-CN.md) 的 F03 节。

## 文件处理与限制

- 文件通过浏览器的 `FileReader` 在本地读取和解析，当前查看流程不需要将文件内容上传到后端。
- 文件选择器支持 `.jsonl`、`.json`、`.log` 和 `.txt`，但内容仍按 JSONL 规则处理：每个非空行应是一条完整、独立的 JSON 数据。跨多行的普通 JSON 文档不适用。
- 空白行会被忽略；无效 JSON 行会保留并显示错误提示，不会导致整个文件解析中断。
- 当前实现会一次性读取并解析整个文件。虚拟滚动优化的是列表渲染，超大文件仍可能受到浏览器内存和解析耗时的限制。
- 已打开的文件保存在页面内存中，刷新页面后需要重新打开；主题、JSON 阅读设置和记录大小偏好在浏览器本地存储可用时会保留。
- 中文 README 仅提供中文使用说明，不改变应用界面的语言。
